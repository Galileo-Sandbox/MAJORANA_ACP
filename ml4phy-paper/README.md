# ML4PS 2026 paper artifact

This directory is the reproducibility package for the ML4PS 2026 study of
energy-dependent classifier-cut efficiency in Majorana Demonstrator
calibration data. It contains the frozen protocols, executed analysis code,
compact numerical results, figures, data-budget accounting, and provenance for
all paper experiments completed through the mechanism-control campaign.

The estimand is the probability that an event passes the fixed classifier cut.
New paper text calls this quantity **efficiency**. Older filenames and schema
fields retain the word `acceptance` for compatibility.

## Start here

1. Read [ARTIFACT_REPRODUCIBILITY.md](ARTIFACT_REPRODUCIBILITY.md) for the
   reproduction levels, exact commands, external inputs, and limitations.
2. Read [reports/data_budget_ledger.md](reports/data_budget_ledger.md) before
   interpreting any data-efficiency claim.
3. Read [reports/phase3_result.md](reports/phase3_result.md) for the completed
   training-budget and dense-GP results.
4. Read
   [review_followup_20260910/reports/final_handoff.md](review_followup_20260910/reports/final_handoff.md)
   for the mechanism controls and their limitations.
5. Read [reports/artifact_release_v1.md](reports/artifact_release_v1.md) for the
   release audit and remaining external-publication requirements.
6. Run the portable verification command from the repository root:

   ```bash
   .venv/bin/python ml4phy-paper/artifact/verify_artifact.py
   ```

   The verifier uses only the Python standard library. A system Python 3.12+
   can be used if the project environment has not yet been created.

## Result inventory

- Phase 1: context-size comparisons, kernel controls, neural baselines, and
  MC-noise diagnostics.
- Phase 2: efficiency-model budgets of 2,000 and 5,000 events.
- Phase 3: the 10,000-event prefix, two additional 5,000-event orderings, and
  the complete dense Bernoulli-GP campaign.
- Presentation exports: 600 neural cells, 10 context-only kernel cells,
  10 pooled-kernel cells, and 10 Bernoulli-GP cells.
- Mechanism controls: 12 new training jobs, 120 new evaluation cells, and
  30 reused full-density cells.

The compact Git artifact independently reproduces the reported bin-level and
regional summaries from committed per-bin exports. Checkpoints, raw waveforms,
and event-level predictions are intentionally external because they are large
or identifying. Their exact logical paths and SHA-256 hashes are retained in
the manifests and run registries.

## Scientific boundary

The strongest result is improved recovery of prespecified sharp regions while
maintaining competitive continuum behavior at the efficiency-model stage. It
is not universal superiority: the 2k setting fails, the 10k response is
nonmonotonic, and the sparse tail remains unfavorable. All efficiency-model
claims are conditional on a classifier pretrained with 18,866 selected events.
The final targets were historically exposed, so the follow-up analyses are not
untouched-test experiments. Reference-band agreement is a descriptive
finite-reference diagnostic, not calibrated interval coverage.

## Language and preservation policy

All paper-specific authored text, code, comments, and figure labels are in
English. Historical filenames and machine-readable keys are preserved so that
their recorded hashes and readers remain valid.
